# Strategy navigation

Authority order is architecture, milestone roadmap, then Product Scope. The
GitHub Delivery Project is mutable execution state and cannot amend these
documents. Follow the repository planning-policy workflow for any authority
change.

`platform-safety-contract.json` is the protected executable registry owned by
the architecture's platform-safety section. It is not a fourth authority layer;
schema, compiler, catalog, and package forms derive from it.

Run `pnpm check` after edits. Planning-policy tests run in the
repository-policy package check and the repository planning-policy workflow.
