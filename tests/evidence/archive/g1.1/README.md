binding-derived CSS/DOM hooks, realm-scoped one-owner runtime cleanup,

implementation revision. The capture writes a preliminary index, extends each
invalidated historical evidence chain without changing prior records, executes
the package and root deterministic commands, and binds sanitized raw output to
the final content-addressed records.

publication, or release-readiness claim. Rollback is the exact G1.1
implementation and evidence commits while retaining superseded evidence for
diagnosis.
