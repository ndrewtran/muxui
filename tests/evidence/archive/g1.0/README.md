# G1.0 retained evidence

This directory retains the public-sanitized packets for `E-G1.0-01` through
`E-G1.0-07`. The artifacts cover the token graph denial corpus, canonical web
and native transform provenance, profile-exact fallback denial, exact
requirement-set closure, foundation dependency boundaries, and static theme
operation with runtime switching explicitly unavailable, plus the closed
platform-safety declaration, projection, and consumer-weakening denial corpus.

Run `node tests/evidence/capture-g1.0.mjs` from the exact committed source
revision. The capture writes a preliminary G1.0 index, extends only invalidated
historical evidence through digest-linked append-only recertification chains,
executes the deterministic workspace checks and agent-evaluation status check,
then binds the sanitized outputs into the final content-addressed records.

Rollback remains bounded to reverting the exact G1.0 implementation and
evidence commits, retaining failed evidence for diagnosis, keeping every
package private, and preserving the prohibition on publication.
