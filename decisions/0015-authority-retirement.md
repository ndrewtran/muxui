# Decision 0015: repository migration-authority retirement

- Status: accepted
- Decision owner: Andrew
- Scope: tracked repository authority and public guidance
- Effective: 2026-09-12

## Decision

Andrew authorized retirement of obsolete repository migration records and
provenance-only language from tracked Mux UI authority, decisions, guidance,
and public token descriptions. The retired attribution is replaced with
`Copyright (c) 2025 Andrew`. Exact pre-change bytes are preserved in the
ignored `.migration-archive/` recovery area, including the preflight
`authority-originals/` and recovered Git-base archives. Current canonical
token, theme, component, and API records remain Mux UI-owned and describe
current use; unrelated third-party licence and notice records remain
preserved.

This retirement preserves Product Scope `8.0.0`, immutable Scope IDs, the
React-first, Mux-owned API, React Aria Components `1.20.0` as an internal
substrate, private Scale authoring, optional Tailwind consumer integration,
the fixed 53-family R1 floor plus the exact 21 supplemental roots, deferred
native and framework-free web tracks, accessibility and privacy requirements,
and publication, release, and final-merge stops.

It changes no token values or IDs, public API, package or platform boundary,
support claim, lifecycle, or release status. The archive is recovery-only and
ignored. This decision authorizes the described local cleanup, not new evidence
acceptance, support or release claims, Git history rewriting, Project updates,
publication, deployment, or other external mutations.
