  uses a non-default `codex/` branch.
- Every PR is frozen, deterministic checks pass, profile-selected independent
  reviews are clear, hosted checks are green on the exact head, and the
  protected merge method preserves required evidence history.
- Every merge receives exact parent/tree/default-branch verification before
  tracker synchronization or cleanup.
- Project writes re-read identity, README, fields/options, views, workflows,
  item IDs, and issue bytes; apply only the authorized exact preview;
  fail closed on drift or write-set growth; and verify the result.
- A local or family failure cannot be translated into support, lifecycle,
  milestone, release, or evidence acceptance. A shared-baseline failure
  invalidates every affected lock.
- Manual and assistive-technology evidence required by an exact risk contract
  is not automated away or waived.
- Before Project, R1, evidence, or routine Git operations, the private owner
  `tooling/audits/repository-policy/src/r1-continuous-execution-verify.mjs`

  authority, acceptance, source, proof, review, Project, and Git input. The
  accepted envelope's bounded verifier-bootstrap PR is the sole exception.
